📖 Weekly Overview

This week we level up our numerical toolkit. Bisection search is O(log n) — far faster than exhaustive enumeration. Newton-Raphson converges quadratically, doubling correct digits each step. These are the workhorses of computational engineering.

🎯 Learning Objectives

By the end of this week, you will be able to:

  • Implement bisection search from scratch
  • Explain logarithmic vs. quadratic convergence
  • Apply Newton-Raphson for fast root-finding
  • Compare all three numerical methods
