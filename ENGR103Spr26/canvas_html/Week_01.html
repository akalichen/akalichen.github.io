📖 Weekly Overview

This week introduces you to Python programming through the lens of biological and environmental engineering. We explore what computation is and how Python can solve real problems in fields like electromicrobiology, water quality analysis, and bioprocess engineering.

🎯 Learning Objectives

By the end of this week, you will be able to:

  • Explain declarative vs. imperative knowledge
  • Create and use Python variables with correct types
  • Perform arithmetic and comparison operations
  • Set up and use the Spyder IDE
